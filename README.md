# Machine Learning for DevOps

A structured Machine Learning course focused on ML fundamentals and their connection to DevOps, MLOps, and production AI workflows.

## Course Roadmap

### 00 — Python for ML
Python fundamentals required for Machine Learning, followed by NumPy, Pandas, and Matplotlib.

### 01 — ML Fundamentals
- What is Machine Learning?
- Why Machine Learning?
- Limitations of Machine Learning
- Linear Regression
- Sales Prediction and Forecasting
- Logistic Regression
- Supervised vs Unsupervised Learning

### 02 — Scikit-Learn
- Introduction and core components
- Regression problems
- Independent and dependent variables
- Training models
- Model evaluation
- Feature scaling
- Polynomial regression
- K-Means

### 03 — Supervised Learning
- Linear Regression
- Logistic Regression
- Decision Trees
- Random Forest
- SVM
- KNN
- Time Series Forecasting

### 04 — Unsupervised Learning
- K-Means Clustering
- Dimensionality Reduction
- LDA
- PCA

### 05 — Projects
End-to-end projects combining the course concepts.

### 06 — Interview Preparation
Conceptual, practical, and scenario-based ML interview preparation.

### 07 — MLOps Foundation
Model lifecycle, deployment, automation, monitoring, and production ML workflows.

## Learning Approach
Each topic will progressively include:
1. Concept and theory
2. Real-world use cases
3. Python implementation
4. Practical exercises
5. Visualizations where useful
6. Interview questions
7. Scenario-based understanding
8. Reusable notes and reference material

The repository will be updated continuously as the course progresses.
